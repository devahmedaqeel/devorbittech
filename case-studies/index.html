MediReport AI — Medical Lab Report Scanner & OCR Engine

An intelligent cross-platform mobile application and backend API pipeline designed to ingest, scan, digitize, and explain unstructured clinical laboratory blood panels for patients and physicians.

The Business Challenge

Patients receiving complex diagnostic lab reports face significant anxiety and difficulty understanding esoteric clinical abbreviations, reference intervals, and out-of-range indicators before consulting a physician.

Proposed Architecture

A client-server microservice model combining a React Native (Expo) mobile frontend with a containerized Python FastAPI backend leveraging PaddleOCR for deep document boundary detection and structured JSON extraction.

Technology Stack

React Native (Expo), Python 3.12, FastAPI, PaddleOCR, MedlinePlus Medical Vocabulary API, Supabase (PostgreSQL), Docker, Pydantic.

Technical Challenges & Solution Implementation:

  • Skewed & Poorly Lit Mobile Camera Photos: Implemented OpenCV perspective transformation and threshold filtering prior to passing document buffers into PaddleOCR, boosting tabular line extraction accuracy by over 38%.
  • Medical Entity Disambiguation: Normalized messy biomarker text (e.g. "Hb", "Hgb", "Hemoglobin A1c") against standard LOINC medical coding schemas via fuzzy matching algorithms and MedlinePlus API queries.
  • Secure Cloud Storage: Integrated Supabase Row-Level Security (RLS) and encrypted AWS S3 buckets to store sensitive medical records with zero unauthorized cross-tenant exposure.

Blissful Blinds Ltd — Commercial High-Velocity Web Platform

A bespoke UK-facing interior blinds manufacturer platform engineered for sub-second page loads, local commercial search visibility, and an instant WhatsApp-based quotation conversion funnel.

The Business Challenge

Heavy WordPress and template-based sites suffered from 4.5+ second mobile load times and poor mobile UX, driving up bounce rates and depressing quote inquiries from homeowners.

Proposed Architecture

A zero-bloat static architecture deployed on global Vercel Edge networks with CSS custom property theming, responsive WebP image pipelines, and friction-free direct-messaging CTA hooks.

Technology Stack

HTML5, Modular CSS3, Vanilla ES6 JavaScript, Vercel Edge CDN, Schema.org LocalBusiness, Google Web Vitals.

Technical Challenges & Solution Implementation:

  • Sub-Second Core Web Vitals: Eliminated heavy JS frameworks in favor of optimized modern CSS and minimal vanilla JS, achieving a 98+ PageSpeed score on mobile connections.
  • Local Commercial SEO: Deployed comprehensive Schema.org `LocalBusiness` structured data, Geo-coordinates, and service catalogs to capture localized commercial search queries.
  • Conversion Friction Reduction: Replaced multi-step quote forms with automated pre-filled WhatsApp ordering triggers, directly connecting homeowners with sales representatives in under 10 seconds.

DevSync AI — Developer Synchronization & Workflow Assistant

An autonomous developer productivity companion that integrates with Git repositories and task managers to generate semantic commit messages, changelog documentation, and multi-repo task synchronization.

The Technical Challenge

Engineers working across microservices lose hours manually documenting code changes, writing sprint summaries, and keeping release tracking documentation in sync across distributed repositories.

Proposed Architecture

A Node.js CLI daemon running background Git hooks, paired with an LLM inference pipeline using prompt chaining to parse git diffs into Conventional Commits and Markdown release artifacts.

Technology Stack

JavaScript (ESNext), Node.js runtime, OpenAI / Ollama LLM APIs, Git Hooks API, Commander.js, RESTful microservices.

Technical Challenges & Solution Implementation:

  • Handling Large Unbounded Diffs: Implemented chunked tokenization and file-level ast-filtering to ensure massive multi-file pull requests do not exceed LLM context windows or spike API operational costs.
  • Deterministic Output Structuring: Constrained model outputs via JSON schema enforcement and regex validation to maintain strict Conventional Commits syntax (`feat:`, `fix:`, `refactor:`, `perf:`).
  • Offline & Air-Gapped Operation: Added dual backend support for cloud LLMs (OpenAI) and local lightweight weights running via Ollama for privacy-sensitive enterprise codebases.

Organization Finance Management (OFM)

A multi-platform enterprise financial management and ledgering application built to manage organizational cash flows, department budget allocations, member fee tracking, and automated audit reporting.

The Business Challenge

Organizations relying on ad-hoc spreadsheets struggle with calculation errors, lack of role-based permissions, missing receipts, and cumbersome annual financial reconciliation.

Proposed Architecture

A cross-platform mobile app featuring an offline-first SQLite database architecture with automatic background cloud synchronization and an integrated PDF generation engine for instant ledger receipts.

Technology Stack

React Native, JavaScript, SQLite, React Native Print / HTML-to-PDF, Node.js backend services.

Technical Challenges & Solution Implementation:

  • Double-Entry Ledger Integrity: Formulated strict ACID-compliant database transactions ensuring credits and debits always balance, eliminating accounting drift across distributed offline clients.
  • Dynamic PDF Auditing: Built a native PDF rendering module that translates nested transaction queries into printable audit summaries with cryptographic checksums.
  • Role-Based Access Control (RBAC): Separated administrative authorization levels (Super Admin, Treasurer, Auditor, General Member) with fine-grained view and export restrictions.
